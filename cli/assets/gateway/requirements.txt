# The IANA time zone database. `zoneinfo` is stdlib but ships NO data -- it reads it
# from the operating system, and Windows has no system tz database at all (nor does
# musl/Alpine). Without this package every reporting endpoint fails on Windows the
# moment it resolves a zone, INCLUDING the plain "UTC" the fallback asks for, because
# "UTC" needs the same database as any other key. Unconditional, not marked
# `sys_platform == "win32"`: musl containers need it too, and where a system database
# already exists it is a few hundred KB that changes no behaviour. See
# app/periods.py::zone / NoTZDatabase for what happens when it is missing anyway.
