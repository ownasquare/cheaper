Active sessions chats routed through this gateway — nothing else can be seen

Cheaper sees a chat only when the client sends it through this gateway. A client on its default endpoint — Claude Desktop for macOS, claude.ai in a browser, or any tool whose base URL is still api.anthropic.com — reaches the provider directly and cannot appear here, however many threads are open on screen. To make one visible, start it with export ANTHROPIC_BASE_URL=… pointing at this gateway.
