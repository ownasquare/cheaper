AI coding cost & savings tracker

Pick your tool, set how your work splits across task difficulty, and see your annual cost reduction — broken down by task complexity, by model, and by supported tool.

Most bills come from one habit: reaching for the top-tier model on every call. Cheaper triages each request and routes it to the cheapest model that still clears the bar, escalating only for the hard, correctness-critical work. Estimate that below, then see exactly where the money goes.

How it works with your tool

Point the tool at the Cheaper gateway (it speaks both the Anthropic and OpenAI-compatible APIs), then watch the monitor turn the estimate above into measured numbers:

npx cheaperapp install --all
cheaper gateway start
export ANTHROPIC_BASE_URL=http://localhost:8787
cheaper monitor
